A kicked session does class A only: code, tests, push of `loop/<slug>`.
Default branch is `main`. Remote: https://github.com/wytanj/chengyu-calendar.git

If `gh` is not authenticated, leave PR title/body in `docs/agents/PR.md`.
When DONE_WEBHOOK_URL and DONE_WEBHOOK_KEY are set, POST session_done from agent-home/done-webhook.md.

Class C (outer loop): merge green + vercel --prod when asked.
